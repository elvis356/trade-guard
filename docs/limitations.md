# 目前限制與後續工作

## 後端與資料

本機 PostgreSQL／Redis 主要流程已透過隔離的測試服務驗證，但完整 Compose 堆疊仍需另行驗收。監視目前僅實作 `WASH_TRADE` 與 `CLOSING_MARKUP`；量價異常規則需要 20 日每日 K 線資料來源。事件與稽核資料表的資料庫層級寫入保護，以及 Redis 冪等性加速仍屬後續強化工作。

## 前端

前端已提供登入、角色導覽、商品與帳號管理、委託交易、監控案件、稽核及日終報表工作區；尚未完成真實雲端端到端驗證。管理介面目前以第一頁最多 100 筆呈現帳號／商品、委託、警示與案件，完整跨頁瀏覽仍可後續擴充。

## 尚未提供的功能

密碼重設與帳號停用管理尚未提供。

公開註冊已實作：`/register` 與 `POST /api/auth/register` 可建立 `TRADER` 帳號；建立其他角色仍需管理員權限。
