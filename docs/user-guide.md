# TradeGuard 前端使用者操作指南

← [回 README](../README.md)

本指南說明如何以不同角色體驗 TradeGuard 前端。這是使用虛構資料的教學模擬平台，不涉及真實證券、資金或投資建議。

## 開始體驗

### 線上版

開啟 [TradeGuard 前端](https://trade-guard-frontend-next.vercel.app)。首頁是公開市場總覽，無須登入即可查看啟用中的商品報價；第一次連線時，前端會等待 API、PostgreSQL 與 Redis 就緒，並每 3 秒重試。若服務仍未就緒，請稍後再試。

如果市場沒有報價，代表目前沒有已啟用的商品。請由管理員登入並建立商品，之後返回首頁查看。

### 本機版

請先依[本機開發說明](local-development.md)啟動後端與前端，再於瀏覽器開啟 `http://localhost:3000`。本機範例管理員帳號僅供本機測試，不可用於線上或其他可從網際網路存取的環境；本指南不列出任何初始密碼。

### 登入與角色導覽

1. 選擇頁首的「登入」，輸入管理員提供的帳號與密碼。
2. 登入後會依角色進入對應工作區，頁首也會顯示目前帳號與角色。
3. 要切換使用者時，先按「登出」，再登入另一個帳號。請勿共用帳號，監控案件的提報者與審核者必須是不同使用者。

公開註冊只會建立 `TRADER`（交易員）帳號。`SURVEILLANCE`、`AUDITOR` 與 `ADMIN` 帳號須由管理員建立。帳號需為 3–50 個英數字、點、底線或連字號；密碼需為 12–72 個字元。

## 公開瀏覽：訪客與所有登入角色

### 市場總覽

首頁 `/` 顯示啟用中的商品行情。報價每 5 秒更新；若暫時無法更新，頁面會保留最後一次成功的資料並顯示提示。沒有任何報價時，頁面會提示目前沒有可顯示的商品。

選取任一報價卡，即可前往 `/market/[symbol]` 查看商品參考價、委託簿與近期成交。委託簿與成交會定期更新，但不是即時行情保證。

### 撮合規則

頁首的「撮合規則」會開啟 `/rules/matching`，說明限價委託、價格／時間優先、部分成交等模擬規則。

## 交易員（TRADER）

### 建立帳號

若尚未登入，從登入頁選「建立交易員帳號」，填入帳號、密碼與確認密碼後送出。建立成功後返回登入頁登入。

### 建立與管理委託

1. 登入後進入「委託交易」`/trade`。
2. 選擇啟用中的商品及「買進」或「賣出」。
3. 輸入限價與數量，再選「送出委託」。表單會顯示商品參考價；後端會再次檢查委託條件。
4. 在「我的委託」查看委託編號、商品、方向、限價、數量、已成交數量與狀態。需要時按「重新整理」。
5. 狀態仍為 `NEW` 或 `PARTIALLY_FILLED`，且尚有未成交數量時，可按「取消」。已成交部分不會因取消而撤回。

下單前請留意：

- 僅支援限價買進與賣出；買賣委託符合條件時會由系統依價格優先、時間優先撮合。
- 數量須為 1,000 股的倍數；價格須符合參考價格區間與模擬升降單位。
- 交易時段為台北時間週一至週五 09:00（含）至 13:30（不含）。規則僅供教學示意，不等同完整交易所規章。
- 系統可能部分成交；委託剩餘數量仍可取消。這是模擬委託，不會建立真實持倉或收付資金。

## 管理員（ADMIN）

登入後進入「管理中心」`/admin`。管理員可管理商品、建立角色帳號，也可使用監控與稽核工作區。

### 建立市場商品

1. 在「建立商品」輸入商品代碼、名稱與參考價格。
2. 若希望建立後立即出現在公開市場，勾選「建立後立即啟用」。
3. 按「新增商品」。成功後可在商品清單查看，也可編輯、啟用／停用或刪除。
4. 返回 `/` 確認啟用商品出現在市場總覽。

停用的商品不會作為可交易商品提供給交易員。若商品已有委託或成交，刪除可能會被後端拒絕。

### 建立其他角色帳號

1. 在「建立角色帳號」填寫帳號與初始密碼。
2. 選擇角色：`TRADER`、`SURVEILLANCE`、`AUDITOR` 或 `ADMIN`。
3. 按「建立帳號」，再透過安全管道將帳號與初始密碼交給使用者。

需要示範案件雙人覆核時，請建立至少兩個不同帳號的 `SURVEILLANCE` 使用者：一人提報案件，另一人審核。

## 監控人員（SURVEILLANCE）

進入「監控案件」`/surveillance` 查看最新規則式警示及案件清單。

### 提報警示為案件

在「最新警示」中查看發生時間、嚴重度、規則代碼、商品、成交編號與說明。判斷需要調查時，按該列的「提報案件」；同一警示不可重複提報。警示只是人工調查線索，不代表已認定違規。

目前實作的警示規則為：

- `WASH_TRADE`：同一帳戶同時出現在成交的買方與賣方。
- `CLOSING_MARKUP`：依設定檢查尾盤時間窗、價格偏離與買方成交量門檻。預設值為尾盤 5 分鐘、偏離 5%、視窗成交量 5,000 股；實際環境設定可能不同。

### 審核案件

在案件清單中查看 `PROPOSED` 狀態的案件。提報者本人不能審核該案件；其他監控人員需先填寫必填的「審核備註」，再選擇「核准」或「駁回」。完成後可查看案件狀態、提報者、審核者與備註。已完成的案件不可再次覆核。

## 稽核員（AUDITOR）

登入後進入「稽核報表」`/audit`。稽核員可讀取監控案件，但不能提報或審核案件。

### 檢查稽核鏈與帳本

- 在「驗證稽核紀錄」按「執行鏈驗證」，檢查每筆記錄的雜湊、前後連結及目前鏈頭。結果會顯示檢查筆數；若發現問題，也會顯示異常紀錄資訊。
- 在「帳本對帳」按「執行對帳」，交叉核對委託、成交與委託事件。結果會顯示檢查筆數及差異；若有差異，請保留結果並交由系統維護人員調查。

上述操作是唯讀檢查，不會修改委託或稽核資料。`ADMIN` 也能使用稽核工作台。

### 查看日終報表

從稽核工作台選「開啟日終報表」，或使用頁首的「日終報表」前往 `/reports/daily`。選擇業務日期後可預覽或下載 XML。報表只包含已產生並保存的日期；尚未產生報表時，頁面會顯示不可用狀態。

## 角色與功能速查

| 角色 | 首頁登入後工作區 | 可執行操作 |
|------|------------------|------------|
| 訪客 | `/` 市場總覽 | 查看行情、商品頁、委託簿、近期成交與撮合規則；註冊交易員帳號。 |
| `TRADER` | `/trade` 委託交易 | 建立限價委託、查看本人委託、取消尚有未成交量的委託。 |
| `SURVEILLANCE` | `/surveillance` 監控案件 | 查看警示與案件、提報案件、審核其他監控人員提報的案件。 |
| `AUDITOR` | `/audit` 稽核工作台 | 驗證稽核鏈、執行帳本對帳、查看日終 XML 報表；監控案件唯讀。 |
| `ADMIN` | `/admin` 管理中心 | 管理商品、建立角色帳號；並可使用監控案件（唯讀）與稽核工作台。 |

若開啟無權限的工作區，請返回市場總覽並使用正確角色的帳號登入。前端角色限制提供操作引導；實際權限仍由後端驗證。

## 常見狀況

| 狀況 | 建議處理方式 |
|------|--------------|
| 市場總覽沒有商品 | 請管理員建立並啟用商品，再返回首頁或重新整理。 |
| 交易頁沒有可選商品 | 請管理員確認至少有一項商品已啟用。 |
| 下單被拒絕 | 檢查交易時段、商品是否啟用、限價、升降單位及 1,000 股整數倍數；依頁面錯誤訊息調整。 |
| 案件不能審核 | 確認案件仍為 `PROPOSED`、目前使用者不是提報者，且已填寫審核備註。 |
| 首次開啟頁面停留在服務檢查 | 後端可能正在啟動或喚醒；稍候讓頁面自動重試。也可查看 [readiness 狀態頁](https://tradeguard-api-vy1t.onrender.com/api/health/readiness)。 |
